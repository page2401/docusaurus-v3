# 嵌套子页 B：多级子目录与侧边栏同步机制

在 Docusaurus v3 中开启 `{ type: 'autogenerated', dirName: '.' }` 后，新增子目录文档会自动进入侧边栏而无需修改根部 `sidebars.js`；通过在同级放置 `_category_.json`（`{ "label": "嵌套子目录实测 (_category_.json)", "position": 2, "collapsed": false }`），即可将英文目录名 `nested` 映射为中文分组名并默认展开，代价是文档树中需散落少量 JSON 元数据文件。
