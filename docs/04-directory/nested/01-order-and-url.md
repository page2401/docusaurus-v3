# 嵌套子页 A：排序前缀与 URL 纯净度权衡

在母版目录 `docs/04-directory/nested/` 中，文件名使用 `01-order-and-url.md` 以保证在 Git 与代码编辑器中按阅读先后顺序排列。Docusaurus 默认启用 `numberPrefixParser: true` 自动吃掉文件名前缀生成干净 URL，也可像本子站一样配置 `numberPrefixParser: false` 原样保留文件名路由并兼容纯相对路径 `.md` 互链。
