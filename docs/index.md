# Docusaurus v3 静态网站生成基准实测

本站点由独立仓库 [`page2401/docusaurus-v3`](https://github.com/page2401/docusaurus-v3) 构建，基于主仓库 `page2401.github.io/docs/` 的标准 GFM 原始母版派生适配而来，用于量化 **Docusaurus v3 (`3.10.2`)** 在 MDX 3 严格语法、三冒号 Admonitions、Mermaid 图表、KaTeX 公式与 `_category_.json` 自动侧边栏上的真实工程表现。

## 五大基准测试章节导航

| 章节路径 | 测试维度 | Docusaurus v3 (`3.10.2`) 核心实测特征 |
| :--- | :--- | :--- |
| [`01. 专属标注与元数据`](./01-annotations.md) | 专属标注与 MDX 3 边界 | 原生支持 `:::note`、`:::tip[标题]`、`:::warning`、`:::danger` 与 `<details>`；MDX 3 严格拦截正文中未转义的裸 `<id>` 与 `{}`；未原生转换 `> [!NOTE]` |
| [`02. 流程图与时序图`](./02-diagrams.md) | 流程图与时序图 | 官方一等公民 `@docusaurus/theme-mermaid@3.10.2` 直连 `mermaid@12.3.0`，支持深浅色主题联动切换 |
| [`03. 数学公式排版`](./03-math.md) | 数学公式排版 | 接入 `remark-math@6.0.0` + `rehype-katex@7.0.1` + 本地化 `katex@0.19.1` 样式与字体（零外部 CDN 依赖） |
| [`04. 目录结构与路由取舍`](./04-directory/index.md) | 目录结构与 `_category_.json` | `docs/` 单层隔离 + `autogenerated` 侧边栏 + 子目录 `_category_.json` 优雅解决中文分组命名 |
| [`05. 高阶代码块与语法高亮`](./05-code-blocks.mdx) | Prism 代码块与 `@theme/Tabs` | 原生支持 `title="..."`、`{3,7-9}` 与 `// highlight-next-line`；行级词法 Diff 需自定义 `magicComments`；多语言组使用 JSX `<Tabs>` |

## 子模块精确锁定版本档案

| 依赖模块 | 精确锁定版本 | 在本子站中的职责 |
| :--- | :--- | :--- |
| `@docusaurus/core` | `3.10.2` | Meta 开源 React 静态文档核心引擎（Docs-only 模式） |
| `@docusaurus/preset-classic` | `3.10.2` | 官方经典文档预设（含 MDX 3 编译管线与 Infima 主题） |
| `@docusaurus/theme-mermaid` | `3.10.2` | 官方 Mermaid 代码块主题扩展 |
| `mermaid` | `12.3.0` | 第 12 代流程图、时序图与状态机渲染引擎 |
| `remark-math` / `rehype-katex` | `6.0.0` / `7.0.1` | 构建期 LaTeX 公式 AST 解析与 KaTeX HTML 生成 |
| `katex` | `0.19.1` | 本地静态托管 `static/katex/` 样式表与 Webfont 字体资源 |
| `react` / `react-dom` | `19.3.1` | 底层 UI 渲染运行时 |
